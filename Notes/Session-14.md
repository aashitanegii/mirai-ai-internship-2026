# 5. AI Grading & Agentic Workflows

One of the important concepts introduced was **AI grading and agentic workflows**.

### Traditional AI application

`User Input → AI → Response`

### Agentic workflow

`User Input → AI → Analyze → Decide → Perform Task → Evaluate → Output`

The idea is to give the AI a specific role, objective, context and workflow.

For example:

**Resume Analyzer**

`Resume → Extract Information → Compare with Job → Score → Identify Gaps → Generate Recommendations`

This makes the application feel much more like a real AI product.

---

# 6. Understanding Agentic AI Systems

Agentic AI systems are designed to perform tasks toward a defined objective.

Important components:

* **Input**
* **Context**
* **Reasoning/analysis**
* **Tool/API interaction**
* **Decision-making**
* **Action**
* **Output**
* **Feedback/evaluation**

For the capstone, this means the AI should have a **clear job to perform**.

A generic:

> "Ask me anything"

application would be much weaker.

A focused:

> "Analyze this information and generate a structured action plan"

application demonstrates much stronger product thinking.

# 8. Capstone Project Marking Criteria

The capstone carries **100 points**.

### Technical Implementation & Architecture — 25 points

The project should:

* Run cleanly
* Have no terminal/runtime errors
* Use `st.session_state`
* Use `st.form`
* Use Pandas DataFrames
* Have clean application architecture

### AI Integration & Prompt Engineering — 20 points

The project should demonstrate:

* Gemini API
* System prompts
* Dynamic `f`-strings
* Context-aware prompting
* Multimodal functionality
* Camera and/or microphone where appropriate

The AI needs to function as a **tailored engine**, rather than a generic chatbot.

### UI/UX & Data Visualization — 20 points

Use professional Streamlit UI elements such as:

* `st.columns`
* `st.expander`
* `st.metric`
* KPI cards
* Metric deltas
* `st.data_editor`
* `st.map`
* Charts/data visualization

### Deployment & Cloud Engineering — 15 points

The application must be deployed on a supported platform such as:

* Streamlit Community Cloud
* Render
* Hugging Face Spaces

`requirements.txt` must contain the necessary dependencies and avoid local-only dependencies.

### GitHub / Open-Source Branding — 10 points

The GitHub repository should include:

* Customized README
* Project explanation
* Architecture
* Setup instructions
* Live application link
* Professional repository structure

### System Design & Documentation — 10 points

Include:

* System architecture diagram
* Data flow
* API strategy
* Logic modules
* Technical design explanation

Mermaid or Lucidchart can be used for the architecture diagram.

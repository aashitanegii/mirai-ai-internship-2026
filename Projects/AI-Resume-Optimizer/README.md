# AI Resume Optimizer

## What we built
- A Streamlit app that analyzes a resume against a target job role.
- A sidebar where the user can choose a job role and adjust the analysis level.
- An ATS-style scoring system that checks skills, keywords, resume sections, and formatting.

## What we learned
- How to build a practical AI-powered app with Streamlit.
- How to compare user input with a predefined skill database.
- How to create a simple but useful resume evaluation experience.
